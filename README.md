# My To-Do

A minimal, typewriter-style to-do app in a single HTML file.

- **Daily**: today's and tomorrow's to-dos. Click a to-do to edit it.
- **All to-dos**: every to-do with due dates, as a list or a month calendar.
- To-dos are saved in your browser (localStorage).

## Use it in a browser
Open `index.html` in any browser.

## Mac app
`mac-app/` wraps the page in Electron. See [mac-app/README.md](mac-app/README.md) for build steps.
